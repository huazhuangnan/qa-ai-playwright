# 功能风险扩展目录

先应用[通用测试基线](universal-baseline.md)。本目录只补充匹配当前功能的扩展场景。

以下条目均为思考启发，不是固定用例。状态码、提示、阈值、权限和状态变化必须由需求、契约或用户确认。
每个模式都要先判断功能相关性、失败影响和执行条件。资料不足时标建议或待确认，不机械覆盖全部条目。

## 跨层风险

以下场景在功能确有依赖时选用，不要求每个任务全部覆盖。

| 风险范围 | 候选场景 |
| --- | --- |
| 页面生命周期 | 刷新、返回、前进、深链接、多标签页和未保存修改 |
| 网络韧性 | 慢响应、断网、超时、重试、乱序响应和恢复 |
| 并发一致性 | 双击提交、重复请求、旧版本写入、竞态和超时后重试 |
| 数据演进 | migration、backfill、软删除、缓存失效和旧数据兼容 |
| 契约演进 | 新增可选字段、缺少响应字段、错误结构变化和 API 版本 |
| 时间与地域 | 时区、夏令时、日期边界、locale 和币种 |
| 依赖降级 | 下游不可用、部分成功、熔断、限流和人工恢复 |
| 外部影响 | 邮件、消息、支付、Webhook 和第三方写入 |
| 变更影响 | 从源码 diff、路由、schema 和共享模块识别回归范围 |
| 可观察性 | request ID、correlation ID、审计记录和清理结果 |

## 源码驱动场景

源码用于发现候选行为。正式预期仍以需求、契约或用户确认为依据。

| 源码位置 | 候选场景 |
| --- | --- |
| 页面、路由和组件 | 入口可达、跳转、空状态、加载态和错误态 |
| 表单和校验 | 必填、类型、长度、格式、默认值和提示 |
| 请求和中间件 | 认证、重试、超时、重复请求和响应映射 |
| 权限分支 | 未登录、角色、资源归属和拒绝后的副作用 |
| 数据层和事务 | 唯一性、状态变化、回滚、并发和审计 |
| 功能开关和配置 | 开启、关闭、组合和错误配置 |
| 现有测试和 fixtures | 已覆盖行为、复用方式、隔离和缺口 |

## 认证与会话

适用：登录、注册、SSO、MFA、验证码、密码重置。

| 风险 | 候选场景 |
| --- | --- |
| 凭证 | 正确、错误、空值和输入边界 |
| 提示 | 错误提示可理解，且不泄露敏感信息 |
| 会话 | 创建、刷新、过期、退出和并发会话 |
| 访问控制 | 未登录跳转、登录后回流和角色权限 |
| 防滥用 | 锁定、限流、验证码和重试策略 |
| 恢复 | 密码重置、MFA 丢失和异常中断 |
| 外部登录 | OAuth/OIDC 回调、拒绝、过期和取消 |
| 账号状态 | 新账号、未验证、禁用、锁定和待激活 |
| 链接流程 | 验证邮件、邀请和重置链接的过期、重发、重复使用和错误账号 |
| 会话安全 | 记住登录、刷新、退出全部设备、改密后旧会话和角色变化 |

## 专项边界

性能、安全审计、可访问性和兼容性需要单独的范围、指标和证据。功能流程通过不能代替专项验收。

| 触发条件 | 专项范围 |
| --- | --- |
| 大数据量、长列表、复杂报表或明确耗时指标 | 性能预算、容量和资源消耗 |
| 登录、权限、外部输入、文件或敏感数据 | 安全审计、威胁建模和授权测试 |
| 键盘、焦点、读屏、缩放或表单错误提示 | 可访问性审计 |
| 浏览器、设备、屏幕尺寸或系统版本矩阵 | 兼容性测试 |
