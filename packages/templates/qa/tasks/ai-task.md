## 输入条件

- **配置变量与身份：** ［QA_ENV、input-index.md 中的变量名、角色、租户与资源］
- **数据与业务预期：** ［隔离数据、预期结果及契约］
- **数据清理方式：** ［待填写］
- **服务依赖与隔离：** ［数据库、缓存、队列、容器和临时数据］
- **进程生命周期：** ［启动、等待就绪、执行、停止和清理］
- **凭证获取方式：** ［环境变量、CI secret 或密钥系统名称；不填值］
- **已读资料：** ［已读取的索引、章节、文件和来源］
- **未读资料：** ［尚未读取或无法访问的资料及原因］
- **已确认要求 / 待确认问题：** ［分别列出］

## 执行范围

- **允许修改的文件：** ［路径］
- **允许执行的操作：** ［命令或动作；写操作限定测试环境］
- **测试标签：** ［smoke / regression / contract / integration / 其他］
- **API 门禁：** ［必选 / 不适用，及依据］
- **禁止操作：** ［待填写］
- **上下文策略：** ［索引 / 标题 / 相关章节 / 全文；复用已读资料］
- **静态化交付：** ［不需要 / 静态站 / 单文件 HTML / PDF / 截图］
- **验收命令与预期结果：** ［待填写］

沿用项目现有配置和 fixture。业务预期不明确时列出问题；生成前确认测试计划，修改后检查 diff 并运行目标用例。不得通过删除断言、跳过用例、放宽预期或增加重试掩盖失败。

## 交付要求

说明修改文件、实际执行命令、结果分类、证据位置、清理结果和剩余问题。区分通过、失败、跳过、重试后通过与未执行。无法运行时注明原因，不报告为通过；输出中不得包含凭证。
