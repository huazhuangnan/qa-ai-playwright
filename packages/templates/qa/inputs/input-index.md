## 环境变量登记

`QA_ENV`、`UI_BASE_URL` 和 `API_BASE_URL` 是基础项。
实际变量按接口契约、认证方式、角色权限和测试数据策略增加。
这里只记录变量名、用途、来源和值形态，不记录真实值。

| 变量名 | 类别 | 用途 | 适用环境 | 获取位置 | 是否必填 | 校验方式 |
| --- | --- | --- | --- | --- | --- | --- |
| `QA_ENV` | 环境选择 | 选择 `.env.<环境>` | 全部 | 本地配置或 CI | 是 | `dev`、`stg` 等有效值 |
| `UI_BASE_URL` | 页面入口 | 页面服务地址 | UI | `.env.<环境>` 或 `vars` | 按项目 | 可访问且协议正确 |
| `API_BASE_URL` | API 入口 | 接口服务地址 | API | `.env.<环境>`、`vars` 或 secret | 按项目 | 可访问且协议正确 |
| `BASE_URL` | 兼容入口 | 旧项目回退地址 | 全部 | `.env.<环境>`、`vars` 或 secret | 否 | 新项目优先用分离变量 |
| `QA_API_TOKEN` | 认证 | API Token | 按项目 | secret 或密钥系统 | 按项目 | Token 有效且权限最小 |
| `QA_API_TOKEN_HEADER` | 认证 | Token 请求头名称 | 按项目 | `.env.<环境>` | 否 | 与接口契约一致 |
| `QA_API_AUTH_SCHEME` | 认证 | Token 认证前缀 | 按项目 | `.env.<环境>` | 否 | 与接口契约一致 |
| `QA_API_TIMEOUT` | 执行控制 | API 超时秒数 | 全部 | `.env.<环境>` | 否 | 正数 |
| `QA_AUTH_STATE` | 会话 | 单个手工浏览器登录状态路径 | UI | `.env.<环境>` 或 CI 临时文件 | 按项目 | 文件存在且未提交 |
| `QA_AUTH_ROLES` | 会话 | 需要生成和复用的角色列表 | UI | `.env.<环境>` | 否 | 逗号分隔的唯一角色名 |
| `QA_AUTH_ROLE` | 会话 | 默认浏览器角色 | UI | `.env.<环境>` | 否 | 属于 `QA_AUTH_ROLES` |
| `QA_AUTH_<ROLE>_USERNAME` | 认证 | 角色账号 | UI | secret 或密钥系统 | 按项目 | 账号可用且权限最小 |
| `QA_AUTH_<ROLE>_PASSWORD` | 认证 | 角色密码 | UI | secret 或密钥系统 | 按项目 | 不写入日志 |
| `QA_AUTH_LOGIN_PATH` | 认证 | 登录页路径 | UI | `.env.<环境>` | 否 | 默认 `/login` |
| `QA_AUTH_USERNAME_SELECTOR` | 认证 | 账号输入框 | UI | `.env.<环境>` | 是 | 与登录页一致 |
| `QA_AUTH_PASSWORD_SELECTOR` | 认证 | 密码输入框 | UI | `.env.<环境>` | 是 | 与登录页一致 |
| `QA_AUTH_SUBMIT_SELECTOR` | 认证 | 登录按钮 | UI | `.env.<环境>` | 否 | 默认提交按钮 |
| `QA_AUTH_SUCCESS_SELECTOR` | 认证 | 登录成功元素 | UI | `.env.<环境>` | 二选一 | 元素可见 |
| `QA_AUTH_SUCCESS_URL` | 认证 | 登录成功地址 | UI | `.env.<环境>` | 二选一 | URL 匹配 |
| `QA_AUTH_INDEXED_DB` | 认证 | 保存 IndexedDB 状态 | UI | `.env.<环境>` | 否 | `true` 或 `false` |
| `QA_ALLOW_PRODUCTION_WRITES` | 写保护 | 允许生产写入 | prod | `.env.<环境>` 或 CI | 否 | 默认 `false` |
| `REQUIRE_API_TESTS` | 门禁 | API 缺失配置时失败 | CI | 工作流 | 否 | `0` 或 `1` |
| `PLAYWRIGHT_WEB_SERVER_COMMAND` | 本地服务 | 启动项目服务 | 本地 | `.env.<环境>` | 否 | 命令可启动并响应入口 |
| ［VARIABLE_NAME］ | ［认证 / 角色 / 租户 / 资源 / 数据 / 开关 / 上下文］ | ［用途］ | ［环境］ | ［变量、secret 或密钥系统位置］ | ［是 / 否］ | ［格式与边界］ |

同一变量在 dev、stg 等环境使用相同名称。
认证可包含 Token、Cookie、账号、OAuth 客户端或会话状态。
业务配置可包含角色、用户、组织、租户、项目、资源 ID 和夹具 ID。
数据配置可包含前缀、所有者、唯一性、重置和清理策略。
执行配置可包含门禁、写保护、超时、并发和标签。
功能配置可包含开关、区域、语言、时区、浏览器和构建差异。
