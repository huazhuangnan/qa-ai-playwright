# QA + AI + Playwright v0.0.3

## 改进

- 明确业务模块、测试层级、测试类型和专项质量属性的边界。
- 区分 API、服务集成、单页 UI 与完整 E2E，避免把 `functional` 当作独立测试层。
- 推荐按业务模块与测试层级组织测试目录，并补充数据、角色、外部依赖和结果判定边界。
- 同步 TypeScript 与 Python 模板，将运行器自检归入 `unit`，使用 `functional` 标签表达业务目标。

## 升级

更新 QA 交付包后，执行 `qa skills upgrade <项目目录> qa-core`，将新版 Skill 同步到已有项目。
