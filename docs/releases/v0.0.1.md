# QA + AI + Playwright v0.0.1

这是 QA + AI + Playwright 的首个交付版本。

## 新增

- 提供 Windows、macOS 和 Linux 通用使用者包与开发者包。
- 提供 `qa.cmd` 和 `qa.sh` 跨平台启动入口。
- 支持 TypeScript、Python 或双语言 QA 环境初始化。
- 支持生成 TypeScript 和 Python QA 项目模板。
- 支持环境检查、修复、卸载和状态查看。
- 支持项目检查、模板状态查看、升级规划和安全卸载。
- 提供内置 QA Skills、QA MCP、Playwright MCP 和可选 Agent Browser 集成。
- 提供 TypeScript Playwright Test 和 Python pytest 示例项目。
- 提供 SHA256 校验清单，便于确认下载文件完整性。

## 使用方式

1. 下载本 Release 的使用者 ZIP 文件。
2. 解压并进入 `qa-ai-playwright-版本号-user` 目录。
3. 初始化环境并生成项目：

   ```powershell
   .\packages\qa-cli\bin\qa.cmd env init typescript
   .\packages\qa-cli\bin\qa.cmd project init .\my-qa --language typescript
   ```

需要修改仓库或运行维护测试时，下载同一 Release 的开发者 ZIP。
macOS、Linux 和 WSL 使用对应的 `qa.sh` 入口。完整命令见使用指南。

## 注意事项

- 首次初始化可能需要联网下载运行时和浏览器依赖。
- 测试项目必须放在环境目录之外。
- 真实账号、Token、Cookie 和测试数据不应写入 Release 包。
- 当前 Release 提供源码和启动器，不提供独立平台二进制或 npm 包。
