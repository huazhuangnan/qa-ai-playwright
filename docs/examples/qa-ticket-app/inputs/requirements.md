# 示例应用需求

## 目标

提供一个可运行的全栈工单应用。
应用用于验证 API、数据库、权限、React UI 和 Playwright E2E 的实际能力。

## 角色

| 角色 | 权限 |
| --- | --- |
| 匿名用户 | 登录 |
| 普通成员 | 查看全部工单、创建工单、更新和删除自己的工单、添加评论 |
| 管理员 | 普通成员能力、管理全部工单、分配负责人 |

## 工单

| 字段 | 规则 |
| --- | --- |
| 标题 | 必填，2 到 80 个字符 |
| 描述 | 可选，最多 2000 个字符 |
| 状态 | `open`、`in_progress`、`resolved`、`closed` |
| 优先级 | `low`、`medium`、`high`、`urgent` |
| 负责人 | 可选，必须对应有效用户 |
| 版本 | 更新时必填，用于检测并发冲突 |

## 状态流转

| 当前状态 | 允许状态 |
| --- | --- |
| `open` | `in_progress`、`closed` |
| `in_progress` | `open`、`resolved` |
| `resolved` | `in_progress`、`closed` |
| `closed` | `open` |

## 查询

- 支持标题和描述关键词搜索。
- 支持状态和优先级筛选。
- 支持 `page`、`pageSize` 分页。
- `pageSize` 范围为 1 到 50。
- 默认按更新时间倒序。

## 评论与审计

- 已登录用户可为可见工单添加评论。
- 评论文本为 1 到 1000 个字符。
- 创建、更新、评论和删除产生审计记录。

## 安全

- 未登录接口返回 401。
- 无权限操作返回 403。
- 用户输入按纯文本渲染。
- 会话使用 HttpOnly cookie。
- API 对请求体做 schema 校验。

## 不包含

- 邮件、短信和实时通知。
- 附件上传。
- 支付。
- 生产账号体系和外部 OAuth。

## API 契约入口

- 应用提供 `/openapi.json` 和根据该契约生成的只读 `/api-docs` 页面。
- 契约覆盖示例 API 的方法、路径、认证和响应状态。
- 契约可作为链接或本地 JSON 文件输入测试。业务预期仍以需求和确认规则为准。
