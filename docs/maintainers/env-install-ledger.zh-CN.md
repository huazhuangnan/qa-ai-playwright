# 环境安装台账

[使用人员](../../README.md) | **维护人员**

`state.json` 的 `installations` 按已检查组件记录作用域、来源、路径、版本和状态。CLI 发起全局 npm 安装前写入 `pending`。安装完成并发现路径后写入 `ready`。重跑会检查已有组件，并在路径和版本一致时保留可验证的本环境安装记录。

启动器在 `env init` 前引导 Node。CLI 无法可靠判定 Node 的安装归属，来源记为 `unknown`。旧版环境和中断后发现的组件也可能无法证明来源。不能根据未知来源推断安装归属。

状态记录不证明共享软件没有被其他环境使用。环境卸载不得单凭该记录移除共享软件。安装中断时先核对状态和实际路径，再执行 `env repair`。暂存文件和无法证明归属的共享目录保留。

CC Switch 由显式选项启用。没有启用时不检查或安装该桌面应用。解压完成并确认入口后再发布到共享目录。仅有可验证的待安装标记且目录没有其他文件时允许继续。已发布但缺少所有权元数据的目录保留，需人工核对。
