# 上游版本同步

在仓库根目录执行 `pnpm upstream:sync`。脚本读取官方 npm 注册表和 GitHub Release，更新运行时及 MCP 版本。CC Switch 需要对应平台的发布资产和 SHA256。资产缺失时脚本停止，不写入版本文件。

同步覆盖外部 Skill 来源提交和 Skill 安装器版本。Skill 提交变化时，脚本核对目标提交的仓库许可证。许可证不可确认或与清单不一致时停止写入。

Node、Python 支持策略、项目依赖锁和部分 CI 固定版本不在自动同步范围。同步后检查版本记录、模板变更日志、许可证、安装资产和生成的 diff。按需补充未覆盖的引用。CI 完成相关平台验证后再发布。同步不会安装或升级本机软件。

本次核对时，Anthropic 和 antfu 的新 Skill 提交未能确认许可证，仍保留原提交。许可证问题未解决时，整次同步会停止。

GitHub API 限流时可设置 `GITHUB_TOKEN`。查询失败会终止同步，不把失败当成最新。
