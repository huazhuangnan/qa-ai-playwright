# 文档

- 使用者文档放在 `docs/users/`，维护者文档放在 `docs/maintainers/`。
- 根 `README.md` 只作公共入口，不混入仓库维护细节。
- 用户包发布根 README、全部 `docs/users/` 和模板 `AGENTS.md`。不发布根 AGENTS、`.agents/` 或 `docs/maintainers/`。
- 用户文档只链接包内文件或外部公开地址。维护文档和示例源码不能作为用户操作前置条件。
- 写作前确定读者和入口。使用者只看到完成任务所需的步骤、条件和限制。
- 来源、锁记录、实现和验证规则放在维护文档。
- 文档按任务组织。删除重复背景、过程说明和不改变操作的内容。
- 一句话表达一个主要意思。并列信息使用列表或表格。
- 命令标明平台和执行目录。系统差异使用可展开块。
- 语言页只写该语言的命令、项目结构和报告方式。
- Markdown 模板使用 `［待填写］` 等可见占位符。
- 维护 Skills 不进入使用者安装说明。`packages/skills/builtin/qa-*` 才是 QA 产品能力。
- 文档路径、Skill 职责和版本必须与源码一致。
- 迁移文档时同步源码引用、交付包清单、CI 和本地链接。
