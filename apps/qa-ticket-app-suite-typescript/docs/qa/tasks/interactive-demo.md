# 交互式验收任务

## 目标

验证工单主流程、角色边界、查询、评论和失败恢复。

## 范围

- 本地全新数据库。
- Chromium 桌面和移动视口。
- 普通成员和管理员各一组独立会话。

## 交互门禁

| 门禁 | 确认内容 | 默认行为 |
| --- | --- | --- |
| 范围 | 环境、角色、覆盖和不覆盖项 | 使用本文件和需求 |
| 写入 | 是否允许创建、更新、删除测试数据 | 仅允许临时本地数据库 |
| 预期 | 需求未覆盖时的业务判断 | 暂停并询问用户 |

## 执行顺序

1. 按文档生成测试计划。
2. 按计划生成或更新自动化测试。
3. 执行目标层测试。
4. 失败时保留证据并分类。
5. 只报告实际执行结果。

## 完成条件

- P0 和 P1 用例全部通过。
- 自动化使用独立数据库和独立会话。
- 页面无未处理的控制台错误。
- API 与 UI 数据一致。
- 结果写入执行报告。
