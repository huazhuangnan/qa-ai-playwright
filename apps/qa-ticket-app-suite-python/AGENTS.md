# Python 示例 QA 规则

- 被测应用位于 `../qa-ticket-app/`。只通过 HTTP 和浏览器访问。
- 业务需求、计划和用例位于 `../qa-ticket-app/docs/qa/`。
- 专属任务、用例映射和执行报告放在本项目 `docs/qa/`。
- 测试只使用本地 `127.0.0.1:5173` 和 `127.0.0.1:8787`。
- 每次运行启动独立服务和临时数据库。不要同时运行另一套示例测试。
- 用唯一数据和独立会话。记录并清理创建的数据。
- 测试函数使用 docstring 说明业务目标和关键约束。复杂流程用 `[STEP]` 输出可观察步骤。
- 未执行、失败和跳过分别报告。不要提交凭证、报告或浏览器状态。
