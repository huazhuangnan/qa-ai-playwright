## 契约

### CASE-CONTRACT-001 契约输入与展示

- 需求：可通过链接和本地文件读取 OpenAPI 契约，页面基于同一契约展示接口
- 优先级：P1
- 标签：`contract`
- 前置：本地 API 服务可用
- 步骤：读取契约链接与本地文件，打开文档页面，按契约验证匿名访问和登录后创建工单
- 预期：两份契约一致，页面展示操作；状态码和响应字段符合已确认契约
- 证据：响应、页面和执行报告
- 清理：删除创建的工单

## 认证

### CASE-AUTH-001 普通成员登录

- 需求：匿名用户可登录
- 优先级：P0
- 标签：`smoke`
- 前置：alice 已创建
- 步骤：打开登录页，输入 alice 和 `demo1234`，提交
- 预期：进入工单页，显示 alice
- 证据：页面截图
- 清理：关闭 browser context

### CASE-AUTH-002 密码错误

- 需求：错误凭证不能建立会话
- 优先级：P0
- 标签：`regression`
- 前置：匿名会话
- 步骤：输入 alice 和错误密码，提交
- 预期：显示错误提示，接口返回 401
- 证据：响应和页面文本
- 清理：无

### CASE-AUTH-003 未登录访问 API

- 需求：受保护 API 需要会话
- 优先级：P0
- 标签：`security`
- 前置：无 cookie
- 步骤：请求 `GET /api/tickets`
- 预期：返回 401，响应体为标准错误对象
- 证据：响应
- 清理：无

### CASE-AUTH-004 退出后会话失效

- 需求：退出后不能再访问受保护 API
- 优先级：P1
- 标签：`regression`
- 前置：alice 已登录
- 步骤：退出，再请求 `GET /api/auth/me`
- 预期：返回 401
- 证据：两次响应
- 清理：无

### CASE-AUTH-005 会话刷新保持

- 需求：有效会话刷新后保持登录
- 优先级：P1
- 标签：`smoke`
- 前置：alice 已创建工单
- 步骤：刷新页面
- 预期：仍显示 alice，工单仍存在
- 证据：刷新前后页面
- 清理：关闭会话；临时数据库在下次运行时重建

## 安全与可访问性

### CASE-SEC-001 搜索输入不改变 SQL 结构

- 需求：搜索输入只作为参数
- 优先级：P0
- 标签：`security`
- 前置：存在工单
- 步骤：搜索 `' OR 1=1 --`
- 预期：返回正常结果集，不服务端错误
- 证据：响应
- 清理：删除测试工单

### CASE-A11Y-001 登录页语义

- 需求：表单可用键盘和辅助技术操作
- 优先级：P1
- 标签：`a11y`
- 前置：匿名会话
- 步骤：运行 axe 扫描并键盘提交
- 预期：axe 无 serious 或 critical 问题，键盘路径可完成提交
- 证据：axe 结果、键盘步骤和页面状态；不代表 WCAG 完整合规
- 清理：无

### CASE-E2E-001 多角色完整旅程

- 需求：成员创建和评论，管理员分配和关闭
- 优先级：P0
- 标签：`smoke`、`integration`
- 前置：全新数据库
- 步骤：alice 创建工单并评论，退出；admin 登录并分配，推进到关闭
- 预期：两个角色看到一致数据，刷新后保持，状态合法
- 证据：Trace 和截图
- 清理：关闭 contexts；删除本用例工单；下次运行重建临时数据库
